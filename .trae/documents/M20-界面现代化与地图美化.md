# M20：界面现代化与地图美化（阶段一）

> 目标文档：把"现代游戏布局 / 行走动画 / 导航层级 / 地图美化"对 Elona·侠客游 美术表达的落地，先钉死本阶段（阶段一）的取舍与改动面。
> 用户选定：地图=手绘淡彩地形+图标地标；行走=点目标→显路线→逐步动画走；导航=左侧垂直侧栏；范围=分阶段，先做「地图 + 行走 + 导航」。

## 1. 设计意图

当前世界地图是最硬的"格子棋盘"（`TILE=5px` 密网格 + 灰色格线），点击行走是瞬移（[`_draw_map`](game/scenes/main.gd) 画格线、[`_walk_to`](game/scenes/main.gd) while 循环直接定点）。美术方向定为 elona 的手绘浅彩奇境 + 侠客游的水墨/羊皮卷气质：**去掉格线感，换成一张铺满手绘浅彩地形的画布，城市画成淡金地标 + 图标 + 名签**。

不改任何数值与存档语义：世界仍是 120×120 网格、坐标即落盘、城市依旧是点、距离与遭遇照旧——**只改视觉呈现与"走过去"的方式**。

## 2. 阶段一交付（本阶段范围）

### 2.1 世界地图美化（改 `_draw_map` + 一处地形缓存）
- 删除灰色格线循环，改为**确定性程序化浅彩地形**（复用 `DeterministicRNG`，以 `world_seed` 播种）：
  - 值噪音生成海拔：低=浅水、中=草地、高=林地/丘陵、很高=山（灰褐）；叠加轻量笔触暗点做手绘感。
  - 地形预烘焙成一张 `ImageTexture`（120×120 × TILE = 一次算、缓存、逐帧只 draw 一张），避免每帧 14400 个 `draw_rect`。
  - 地图外缘画一张羊皮纸/水墨风的圆角画框，弱化"窗口贴边"的硬感。
- 商路线、衰退红环保留；城市从"金色方块"改为**淡金地标 + 图标（城堡/镇墙形）+ 名签外排**；化身改为青色小圆点 + 轻微呼吸。
- 命中测试 `_city_at_point`/`_tile_at_point` 不变（仍是网格语义），图标只是放大的可点热区。

### 2.2 点击行走 → 路线 + 逐格动画（`_walk_to` 重写 + 新增 `_process`）
- 点击目标后：BFS/回退 `_grid.step` 生成一条可达路径 → 在地图上**高亮画出拟前进路线** → 玩家沿路径逐格滑动抵达（`_process(delta)` 插值，新增 `_walk` 会话态 + `_walk_draw_pos`）。
- 动画完结时**一次性** `_encounter_advance(总步数)`（保持"点一下不连打好几场"的现语义）；状态文案、`再点一次进面板` 规则不变。
- 键盘 `_move` 保持单步瞬移不变；行走中忽略冲突输入/允许重新选点重新规划。
- 无头测试不碰动画：只重写规则路径生成部分，动画仅 `_draw`/`_process` 层，保证 `--test` 回归全绿口径。

### 2.3 左侧垂直导航侧栏（新增 `game/src/ui/hud_nav.gd` + main.gd 分发）
- 新增共享 `HudNav`：一组导航项（世界地图/城市总览/商铺/走私/委托/事件/角色/制作/纪年/居民/城内），`layout` 出左侧纵向列表矩形、高亮当前 `_view`，`hit` 供命中测试。
- 二级/面板视图（城市/交易/走私/委托/事件/角色/制作/纪年/居民/城内）在 `_draw` 左侧画侧栏，`_handle_mouse_button` 先命中侧栏再下放到面板——把「返回地图」语义收进导航项，逐级可回退。
- 地图/开局/战斗/遭遇视图不画侧栏（保持专注）。

### 2.4 不做（押后到阶段二）
- 全场景面板统一样式、控件级现代化（涉及全部 ViewModel/Panel）。
- 花哨 UI 特效（粒子/位移动画/阴影深度）。

## 3. 取舍记录（对齐技术设计文档 D 表风格）

| 取舍 | 结论 |
|---|---|
| 地形用代码程序化还是 Seedream 出图 | 阶段一**代码烘焙浅彩地形**（确定性、网格对齐、无素材管线、可无头回归）；Seedream 作为阶段二素材（羊皮纸边框/地标贴图）另行接入 |
| 行走仍是回合/格语义吗 | 是。动画只是"走过去"的呈现，动一次结算一次遭遇不连打；键盘/存档/坐标全不变 |
| 侧栏会不会盖住面板内容 | 阶段一做成左侧窄栏覆盖最左列，命中优先；面板各自版式收窄即为阶段二工作 |
| `_process` 引入 | 仅行走动画期消耗，空闲即返回，不影响无头测试确定性 |

## 4. 验收
- `--headless --path game --import` 无脚本错误。
- `--headless --path game -- --test`：既有 2246 全绿 + 新增路径生成/侧栏命中若干断言。
- 窗口内目检：地图无格线、地形浅彩、城市为图标地标；点击显路线并逐格走过去（非瞬移）；二级视图左侧有可点侧栏、可逐级回退。
