# M19 · 城市可探索空间（城内俯视行走 + 点击进入）

## 背景
现状：城市是世界 120×120 网格上的一个"点"（`map_grid.gd`），点进去只打开一张列表面板（`VIEW_CITY`/`city_panel.gd`），城内 40 座功能建筑（M12 `city_buildings.gd`）只以瓦片画在面板里，**没有可走的城内空间**，也没有"走进而互动"的体验。

用户要求（Elona 风格）：城市应是可自由探索的空间——右击/点击进入后玩家在"城内局部网格"里走动、看到建筑落位与 NPC 落位、走到建筑旁/NPC 旁就能交互。**本里程碑只做城市空间；地图随机副本与旅行商人押后。**

## 方案（遵循既有分层：规则层 / 视图模型 / 面板 / main 接线）

### 第 1 步 规则层：`game/src/core/city_space.gd`（新增，`class_name CitySpace`，全静态，风格对齐 `CityBuildings`）
- 常量：`WIDTH=24, HEIGHT=18`，建筑占地 `FOOTPRINT=3×2`，`GATE` 城门位于下边界某格，`SPAWN` 玩家出生点。
- `layout(city_id, buildings_cfg) -> Dictionary`：用 `DeterministicRNG`（复用 `game/src/core/deterministic_rng.gd`）以 `city_id.hash()` 为种子派生 5 座建筑坐标、NPC 布点、玩家出生、城门。**确定性、可复现、不落盘**（对齐 available_level"可派生就不落盘"口径）。返回 `{w,h,building_slots:[{id,x,y,footprint}],npc_slots:[{npc_id,x,y}],gate,spawn}`。
- `walkable(grid,x,y) -> bool`：建筑占地=障碍、越界不可走。
- `step(grid, from, dx, dy) -> Dictionary`：`{ok,next,at_gate}`；撞建筑/越界 `{ok:false}` 原地。
- `near_building(grid, pos) -> Dictionary`：查邻接正交格的建筑，返回 `{building_id, kind}`。
- `building_kind(cfg, building_id) -> String`：建筑类型 → 视图映射（shop→TRADE、event→VIEW_EVENT、quest→VIEW_QUEST、residents→VIEW_NPC、smuggling→VIEW_SMUGGLING、其余→M12 invest）。
- `near_npc(grid, pos) -> String`：邻格 NPC id。

### 第 2 步 视图模型：`game/src/ui/city_space_view_model.gd`（新增，纯函数）
`build(world, city_id, buildings_cfg, state) -> {grid, player, buildings:[{id,label,rect,kind,level}], npcs:[], gate, nearInteraction, hints}`：把 layout 坐标 × TILE 换算成视图坐标供绘制/命中测试；不做渲染、可无头测试。

### 第 3 步 面板：`game/src/ui/city_space_panel.gd`（新增，静态函数，对齐 `city_panel.gd`）
`draw(canvas, view, rect)`：画街道网格底、建筑色块+短标签、NPC 点、玩家方块、高亮可交互项；`hit_test(view, rect, point)` 返回 `{kind:tile/building/npc/gate}`。复用 `UiTheme` 配色与字号。

### 第 4 步 主场景接线：改 `game/scenes/main.gd`
- 加 `const VIEW_CITY_SPACE: int = 13`；补 `VIEW_HINTS[VIEW_CITY_SPACE]`。
- 会话级状态 `var _city_space = {city_id, player_pos}`（**不落盘**，对齐 `_encounter` 处境）。
- 入口：`_map_click`/右击"已站立/点击的城市"→ `_enter_city_space(city_id)`；进城瞬间仍走既有 `CONTEXT_CITY` 一次性遭遇判定（复用 `_enter_*`）。保留 `VIEW_CITY` 作"城市总览"，空间内按 T 或走到城门进。
- 覆盖新视图的 `_refresh`/`_draw`/`_hit_test_at`/`_handle_mouse_button`/`_unhandled_input` 分支；方向键/WASD 调 `CitySpace.step`，撞建筑则 `_status` 反馈。
- 交互复用既有入口：`near_building.kind` 分流到 `_enter_trade/_enter_event/_enter_quest/_enter_residents/_enter_smuggling`；invest 走 M12 投资；`near_npc` → `_enter_residents(city_id)`。
- 时间取舍：城内走动**不推进时间、不触发野外遭遇**，仅保留进城一次性判定。
- 城门/ESC/T → 返回 `VIEW_MAP` 并重置 `_city_space`。
- 存档：城市空间是纯视觉态，无需改序列化。

### 第 5 步 测试：改 `game/tests/test_suite.gd`（走第 1、2 层，可无头，沿用 `_eq/_check`风格）
1. 布局确定性：同 cityId 两次 `layout` 逐位相等；不同 cityId 排列不同。
2. 落位合法：建筑/NPC/出生/城门都在界内；建筑之间、建筑与门不重叠。
3. 碰撞：建筑格 `walkable==false`；`step` 撞建筑返回 `{ok:false}`。
4. 城门出口：`step` 落到 gate 返回 `at_gate:true`。
5. 建筑邻近：站 shop 邻格 `near_building.kind=="shop"`；隔一格为空。
6. NPC 邻近：`near_npc` 返回正确 id。
7. 视图模型：`build` 坐标×TILE 与 layout 一致、门/玩家/NPC 存在。

> 新 `class_name` 文件需先跑一次 Godot `--import` 注册全局类，再改 `main.gd` 引用（否则 `Identifier not declared`）。
