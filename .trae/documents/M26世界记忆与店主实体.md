# M26 — 世界记忆 · 店主实体（M-B 切片）

## Context（为什么做）

路线图 M-B「后门 + 世界记忆」原包含：罪犯态拒售/黑市后门、训练师双币种、玩家死亡回收因果、
守卫死后更强重生、击杀店主掉神器。规划阶段确认：

- **玩家死亡回收因果已实现**：`Reincarnation.settle_death()`（`game/src/core/reincarnation.gd:342`
  by 行 360-362 把这一世 karma 累计进 `soul.karma_carry`），本次只补一句观察文案，不新增代码。
- **罪犯态 / 训练师双币种本次不做**：训练战当前是免费陪练、无"训练师收钱"落点；罪犯态后门属额外范围，已随用户拍板剔除。
- **用户拍板交付两件套**：①守卫死后更强重生；②**新建可被击杀的店主实体**，击杀掉神器。
  用户明确"是时候把 NPC 实体船创建出来，而不是挂靠在居民列表等玩家对话"。
- 罪犯态阈值 -30 因罪犯态被剔除而无挂载处，**不引入新常量**，避免死代码。

**关键前提**：实体层其实已就绪，无需重写——
- 城守卫 = `SimNpc`（`cityNpcCategories` 里"军中/灰色"职业，含 `sim_npc.gd:31 position_id` 职位字段）。
- `EncounterSystem._roll_city_opponents()`（`encounter_system.gd:380`）→ `_npc_profile()`（`:415`）
  生成的战斗单位 **`unitId = npc.npc_id`**（`:432`），注释明说"谁被怎么了能一路追到那个人身上"。
- `combat.gd` 已按单位写世界标记 `world_flags["combat.<choice>.<unitId>"]`（`:821`），是落盘先例。
- `combat.gd` 掉落管线：倒地`_fall`→ 搜身`DOWNED_SEARCH`→ `_roll_loot`（`:935`），`_roll_loot` 产
  `{unitId,templateId,...,rarity}`；稀有度档含 `legendary/dragonforged`。
- 战后结算钩子：`main.gd._resolve_encounter_combat()`（`:3136`）+ `_combat_outcome_label()`（`:3152`）。

因此本里程碑是「在已存在的实体/标记层上叠加两类世界记忆规则 + 店主实体化」，不新造 NPC 框架。

## 实现步骤

### 1. 规则层 `game/src/core/world_memory.gd`（新建，class_name WorldMemory，纯函数）
沿项目「能派生则派生、落盘用 world_flags」惯例，全部静态函数、无 IO，可无头断言：
- `guard_boost(world, city_id) -> Dictionary`：读击杀守卫记忆 → 返回该城守卫再生成时的
  增强叠层 `{hpMult, attackMult}`（或档位加成）。击杀次数越多加成越高，封顶。
- `record_guard_claimed(world, city_id)`：写入世界记忆（`world.world_flags["memory.slaughter.<city_id>"]`
  计数 +1）。**世界记代价不记恨**：不写"谁杀的"，只写"这城曾有守卫被击杀"。
- `guard_boosted_stats(unit, boost) -> unit`（可选）：把叠层应用到 `_npc_profile` 产出的守卫单位。
- `shopkeeper_boost(world, city_id)` / `record_shopkeeper_fallen(world, city_id)`：店主对应记忆，
  击杀店主在此城留下「店主倒下」的永久代价（店主空缺/换代），供后续买卖/事迹读取。

### 2. 店主实体化
- 店主 = 每城一个**具名职位** `SimNpc`，`position_id="shopkeeper"`、`is_named=true`、职业映射到店主。
  - 生成位置待实现确认：优先在世界模拟建城出生时补一个店主职位（读 `worldsim`/`world_state` 建城
    逻辑定位；若 sim 已按 `position_id` 生成则直接沿用）。**实现第一步先读建城/职位生成代码确认落点**，
    做不到就退化为 `main.gd` 懒生成 + `WorldState` 落盘（复用 `world.get_npc`/存档）。
- 店主可被击杀：生成的守卫/店主战斗单位都走既有战场（城内可遇城中 NPC），店主实体作为同城对手
  之一参与 `_roll_city_opponents`（把店主职位纳入候选池，仅在玩家主动触及时可敌）。
- 击杀店主 ⇒ 掉神器：在战后消费 `_combat.loot` / 击杀结果时，若被补刀/搜身单位是该店店主
  `npcId` ⇒ 强制产出一件 `legendary/dragonforged`（复用 `_roll_loot` 或直接 `_pick_item` 高档），
  并写 `WorldMemory.record_shopkeeper_fallen`。

### 3. main.gd 战后杀记忆接线
在 `_resolve_encounter_combat()`（胜利分支 `won`）里，遍历战败敌方单位的处置结果（读 `_combat.outcome`
/ 各 `unit` 的 `handled/dead`），按 `npcId`（守卫职业 / 店主职位）调用对应 `WorldMemory.record_*`，
再据此在下次守卫生成处套 `guard_boosted_stats`（挂在 `_roll_city_opponents` 产出的守卫上，或遭遇
生成后灾区消费）。保持一条收口、不改战斗本身。

### 4. 文案（P8 筛，每通道一句"玩家可观察的现象"）
