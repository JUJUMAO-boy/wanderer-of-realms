# M28 — M-B 后门收口：偷窃通道 + 变装绕过

## Context（为什么做）

M-B「后门 + 世界记忆」已收口 M26（守卫重生 + 店主实体）、M27（罪犯态 + 训练师双币种）。
本轮把 M-B 最后两件**后门佐餐**一起收掉，罪犯这一条轴才算齐活：

1. **偷窃通道（扒窃）**：罪犯被商铺拒卖后的**另一条进项**——蹲在城里、趁夜色下手。
   接上 M25 已交付但一直「没有调用方」的 `Weather.night_steal_modifier`。设计让它**天然偏向罪犯**：
   业力越恶、越爱偷越好得手，夜里比白天好偷整整 +20；毒手越慢、城越乱越容易得手。
   成败都落 karma（偷是罪的底色），败了还落该城声誉（被逮现行）。
2. **变装绕过**：罪犯态橱窗的**后手**——披上「改头换面」斗篷后一段时期内商铺当你是个体面人，
   正常交易。伪装只在黑市卖（正常巷子的店主不会进这种货），用一次管一段自然的白昼，到日子自己失效。
   落地后 M27 在 `criminal_state.gd` 里留的「变装绕过是 M-B 后手」注释就此闭环：`Economy.get_price`
   的 `refused` 由「业力已恶」改成「业力已恶且此刻未变装」。

**铁则**：两件都复刻 CriminalState / TrainingGate 的模式——纯规则层静态函数 + balance.json 数值段 +
可无头钉测；偷窃走 `PlayerAvatar` 已有字段（karma/luck/dexterity/money/reputation），不落新游戏机制字段。

## 实现步骤

### 1. 新规则层 `steal_gate.gd`（class_name StealGate，静态纯函数）
- `success_pct(world, city_id, hour) -> Dictionary`：
  - `base = balance.steal.basePct`（默认 40）。
  - `night = Weather.night_steal_modifier(karma, luck, hour)`（直接作百分点点位加进去，钳 ±50）。
  - `dexterity = (dex - 10) * balance.steal.dexPerPoint`（如 1.0；dex16 → +6）。
  - `security = -city.security * balance.steal.securityPerPoint`（如 0.25；治安40 → −10）。
  - `total = clamp(base + night + dexterity + security, balance.steal.minPct, maxPct)`。
- `attempt(world, city_id, rng, hour) -> Dictionary`：
  - 无化身/无城则 `{ok:false, reason}`。
  - `rng.next_int(10000) < total*100` → 成/败（total 见 success_pct，越界钳在 [minPct,maxPct]）。
  - **成**：`copper = 铜Min..铜Max`（按城 wealth 缩放一下更贴题）增到 `avatar.money`；
    `avatar.set_karma(karma - balance.steal.karmaOnSuccess)`；返回 `{ok:true, outcome:"success", copper, karmaDelta}`。
  - **败（被逮）**：`avatar.set_reputation(city, rep - balance.steal.repOnCaught)`、
    `avatar.set_karma(karma - balance.steal.karmaOnCaught)`；返回 `{ok:true, outcome:"caught", reputationLoss, karmaDelta, reason}`。

### 2. 新规则层 `disguise_gate.gd`（class_name DisguiseGate，静态纯函数）
- `item_template() -> String`：返回「改头换面」模板 id（`consumable_disguise`）。
- `balance_duration() -> int`：读 `balance.disguise.durationDays`。
- `has_disguise_item(world) -> bool`：背包里有一件 `consumable_disguise`。
- `apply(world, today) -> Dictionary`：无化身/没带斗篷拒；有则扣掉一件斗篷、
  `avatar.disguise_until_day = today + durationDays`、`avatar.is_disguised = true`；
  返回 `{ok, untilDay, duration}`。
- `remove(world)`：`is_disguised = false`（主动脱下来）。
- `sync(world, today)`：由 main 在每日边界调用，`is_disguised = disguise_until_day >= today`，
  过期自动剥下（既落 `is_disguised`，也顺手把 `disguise_until_day` 归 -1 表示已失效）。
- `is_active(world) -> bool`：只读 `avatar.is_disguised`——**不含当日/Clock**，规则层零时间耦合。

### 3. 变装接入拒绝判定（Economy 一处改动）
- [economy.gd](c:\Users\YUJINYU\Desktop\侠客游\game\src\core\economy.gd#L258-L265) 的 `refused` 改成：
  `refused = channel==SHOP and (reputation<=_refuse_at or (criminal and not DisguiseGate.is_active(world)))`。
- 报价返回保留 `criminal`（原始业力标记），另加一个 `disguised = bool(q.is_active)` 供 UI 区分文案。
- 黑市恒豁免不变。
- 顺带在 `Economy.is_available`（[economy.gd](c:\Users\YUJINYU\Desktop\侠客游\game\src\core\economy.gd#L353-L367)）
  加「仅黑市」门控：`bool(template.get("blackMarketOnly",false)) and channel!=BLACK_MARKET → false`，让伪装只在黑市上架。

### 4. PlayerAvatar 两个新字段（唯一存档字段增项，缺省安全）
- `is_disguised: bool = false`、`disguise_until_day: int = -1`，进 `to_dict`/`from_dict`（`get` 带缺省，旧存档无损）。
- 放化身上而非灵魂上是有意的：伪装是「身体这件皮」的事，转世换体自然清零，不用清理逻辑。

### 5. balance.json 两个新段
- `steal: { basePct:40, dexPerPoint:1.0, securityPerPoint:0.25, copperMin:20, copperMax:80, karmaOnSuccess:2, repOnCaught:8, karmaOnCaught:2, minPct:5, maxPct:95 }`。
- `disguise: { durationDays:3 }`。

### 6. items.json 一件「改头换面」斗篷
- `{ templateId:"consumable_disguise", displayName:"改头换面斗篷", category:"consumable", subtype:"disguise",
   rarity:"fine", attack:0,…, weight:1, price:180, blackMarketOnly:true, effectText:"披上便换个面貌；管一段自然白昼。" }`。

### 7. main.gd 两条后门入口 + 每日同步
- `_city_space_input` 加键：`KEY_P` → `_city_space_steal()`（挨着居民才能扒）；`KEY_X` → `_use_disguise()`。
- `_city_space_steal()`：`CitySpace.near_npc(layout,pos)` 有目标 → `_start_pickpocket(city_id, rng)`。
  `_start_pickpocket`：`StealGate.attempt(_world,city_id,rng,Clock.now().hour)`，用状态栏 + `_note_events` 报「得手 X 铜 / 被逮个正着」。
- `_use_disguise()`：`DisguiseGate.apply(_world, Clock.now().day)`，成则「你披上斗篷，换个面貌」，败则「你身上没带斗篷」。
- `_on_period_reached` 的 `ClockCore.PERIOD_DAY` 分支加 `DisguiseGate.sync(_world, Clock.now().day)`（过期自动剥下）。
