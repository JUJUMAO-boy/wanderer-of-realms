# M27 — M-B 剩余：罪犯态后门 + 训练师双币种

## Context（为什么做）

路线图 M-B「后门 + 世界记忆」本含多项，M26 已完成「守卫更强重生 + 店主实体」（b9619c0）。
规划时拍板剔除了罪犯态与训练师，本轮用户**重新纳入**并锁定两项：

1. **罪犯态后门**：karma（善恶，全局跨世）≤ -30 → 店主拒卖；但**有黑市的城豁免**（十字路 / 赤沙 / 索恩港，黑市渠道本不问名声即是犯罪通道）；**变装绕过留后续**。
2. **训练师双币种**：新建**训练师职位实体**（类比 M26 店主骨架），城内可交互「受训」，收费 = **铜币 + 业力代价（karma 递减，透支灵魂）**，训练战胜利得熟练度回报；失败学费不退。体现「正路配后门 / 代价无评价」内核。

**铁则**：karma 是已存在于 `PlayerAvatar` 的字段（范围 ±100、跨世保留、`set_karma` 钳制）；罪犯态与训练都复用它，不新增存档字段。规则层纯函数、数值全走 balance.json、可无头钉测。

## 实现步骤

### 1. 规则层：罪犯态判定 + 训练收费（纯函数）
- **新增 `game/src/core/criminal_state.gd`**（class_name CriminalState，静态纯函数）：
  - `is_criminal(world) -> bool`：`avatar.karma <= threshold`。
  - 常量 `CRIMINAL_KARMA = -30`（放下限），但阈值放 `balance.json.criminalKarmaThreshold`（默认 -30）。
- **新增 `game/src/core/training_gate.gd`**（class_name TrainingGate，静态纯函数）：
  - `quote(world) -> {ok, copper, karmaCost, reason}`：读 `balance.training`；钱足且 `karma - karmaCost >= karmaATTR_MIN(-100)` 才 `ok`。
  - `pay(world) -> {ok, reason}`：扣 `avatar.money -= copper`、`avatar.set_karma(karma - karmaCost)`（clampi 走 set_karma）；不足返回拒收理由。

### 2. 罪犯态：拒卖整合进 `Economy.get_price`
- [economy.gd](c:\Users\YUJINYU\Desktop\侠客游\game\src\core\economy.gd#L257-L270) 的 `refused` 扩成：
  `refused = channel==CHANNEL_SHOP and (reputation <= _refuse_at or criminal_state_criminal)`
  其中 `criminal_state_criminal = world.avatar.karma <= balance.criminalKarmaThreshold`。
- 黑市恒 `refused=false` 不变 → 罪犯在有黑市的城靠黑市交易（豁免落地），无黑市城商铺全拒。
- `get_price` 复返里加 `criminal` 标记供 UI 文案区分（「声名扫地」/「业力已恶」）。

### 3. 训练师实体 + 受训入口
- **professions.json**：`positionTemplates` 加 `{ "positionId": "trainer", "displayName": "训练师", "fromProfession": "mercenary", "countPerCity": 1 }`（is_named 天然不参与普通遭遇）。
- **CitySpace**：`KINDS` 与布局新增 `KIND_TRAIN`（训练场）建筑。训练师作为该城具名 NPC（`position_id=="trainer"`）。
- **main.gd**：
  - `_city_space_open_kind` 加 `KIND_TRAIN` 分支 → `_start_sparring(city_id)`。
  - `_start_sparring(city_id)`：先 `TrainingGate.quote(world)`，不 ok 则状态行提示拒收原因并 return；ok 则 `TrainingGate.pay` + `_note_events` 一句「你付了 X 铜与一丝业力，站进场地」，再复用 `_opponent_specs(city_id, rng)` 构造陪练对手 → `_start_encounter_combat`。
  - 战后（`_settle_combat` 胜利分支 / 专用标记）若为训练战且胜 → 给玩家一项战斗技能熟练度 +`balance.training.skillGain`（复用 `avatar.skills`，clampi 100）；被击倒则无回报、学费不退。
  - 用会话字段（如 `_sparring_active`）标记训练战以区分于普通遭遇/委托，避免误伤其它战斗结算。

### 4. balance.json
- 新增段 `criminalKarmaThreshold: -30`；段 `training: { copper: 200, karmaCost: 2, skillGain: 6 }`（量级可调，训练师按它扣两币）。
