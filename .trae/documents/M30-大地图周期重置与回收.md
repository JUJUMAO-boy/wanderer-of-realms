# M30 大地图周期重置与回收（M-C 收尾）

> 承接路线图 M-C 的最后一块缺口：**"地壳变动"事件按周期重置全部可见副本（回收生命周期，P5 图 2）**。
> M-C 的主体（可见遗构点 + 危险度前缀 + 修正词条 + 可见怪物窝点）已在早前作为 WorldSeen 落地；本轮把
> "大地图会随世界时间动起来、看得见的坑与怪定期被震走换新"补完。

## 现状缺口

`WorldSeen` 由世界种子派生、不落盘，但 `main.gd._rebuild_seen()` 只在**每会话一次**（新世界/读档）构建。
也就是说在一场很长的人生里，玩家看到的遗构位置与怪物窝点是一张**静止图纸**——被清的窝点不再有、挖空的遗构始终在原处，
这个世界不会"动"。

路线图 P5 图 2 明确要求：副本有生命周期，世界会按周期把它们"回收"并重新长出来。

## 目标

让大地图可见实体（遗构 + 怪物窝点）随**世界纪元年份**周期性地整体重排：

1. 每到世界纪年结算（PERIOD_YEAR），触发一次"地壳变动"：整片大地的遗构与怪物窝点被震得换位重长；
2. 重排保持"能派生就不落盘、确定性可复现"铁则——同世界同年纪年，图纸逐位一致；被清的窝点随重排回来（回收），
   挖空的遗构换到新的坑位；
3. 读档回来在"当前纪年"重派生，回到与离场时一致的地图（而不是新手期的旧图）。

## 实现步骤

### 1. 规则层：`WorldSeen.era_seed(world_seed, era)`（静态纯函数）

在 `world_seen.gd` 加一个静态函数，把"纪元"折进派生种子：

```gdscript
## 把纪元年份折进派生种子：同世界同纪元逐位一致，纪元变→图纸整体重排。
## alto 位乘子沿袭 DWORLD 系折盐惯例（2654435761），只取低 32 位。
static func era_seed(world_seed: int, era: int) -> int:
	return (world_seed ^ (era * 2654435761)) & 0xFFFFFFFF
```

- `era == 0` → 返回原 `world_seed`（新手期地图与既有行为完全一致，零测试塌方）。
- 吃掉高位的副作用：`world_seed` 本身可负，`& 0xFFFFFFFF` 把它规整到无符号，DERIVE 里的 `^ 0x9E3779B9` 等早已如此处理。

### 2. `main.gd` 接线

- 新增会话态字段：`var _seen_era: int = 0`（跟随 `_seen` 声明区）。
- 新增种子助手：
  ```gdscript
  ## 当前纪年的可见实体派生种子：纪年 0 即世界本原种子；纪元越深，大地越被"震"过。
  func _current_seen_seed() -> int:
      return WorldSeen.era_seed(int(_world.world_seed), _seen_era)
  ```
- `_rebuild_seen()`：把 `WorldSeen.build(_world.world_seed, …)` 改为 `WorldSeen.build(_current_seen_seed(), …)`。
  这一处改动让**读档/新会话也会带着纪年折盐**——于是离场在第 N 年、读档回来仍回到第 N 年的地图。
- 新增地壳变动：
  ```gdscript
  ## 地壳变动（M-C 收口）：整片大地的遗构与怪物窝点被震得换位重长。
  ## 纪年+1 → 图图纸整体重排；窝点存活态随之回收（清掉的怪重新站回地图）。
  func _tectonic_shift() -> void:
      _seen_era += 1
      _seen_bucket = 0
      _rebuild_seen()
      _note_events(["地壳变动：整片大地的遗构与怪物窝点被震得换了位置，旧日的坑被翻出来重长。"])
      _status.text = "地壳变动：大地上看得见的坑与怪，换了一批。"
  ```
- `_on_period_reached` 的 PERIOD_YEAR 分支：在 `settle_year` 之后调用 `_tectonic_shift()`。
  这样纪年推进的同时，大地图跟着"动"——与"第 %d 年结算完成：%d 名居民过世"同拍念给你听。

### 3. 测试（`world_seen.gd` 纯接口 + 纪年折盐）

- `_test_world_seen_era_seed`（新增）：
  - `era_seed(seed, 0) == seed`（新手期=原种子）；
  - 同 (seed, era) 两次一致（确定性）；
  - era 不同 → 种子不同（图纸会换）；
- 复用既有 `_test_world_seen_determinism`：断言同纪年派生逐位一致、纪年不同图纸不同——
  `_seen_snapshot(WorldSeen.build(era_seed(s,1),…)) != _seen_snapshot(WorldSeen.build(era_seed(s,0),…))`。

### 4. main 流程（无头测试，场景层视情况）

- 尽量加点键控：驱动时钟跨过一个纪年边界，断言 `_seen` 里的怪物/遗构整体变化、且 stimulation（清掉的窝点）被回收。
  若时钟/纪年驱动在无头环境下过重则退一步，只钉规则层 + 一次 `_rebuild_seen` 换种后图纸变化。

## 关键取舍（写进技术设计 9.34 节 D-140）

- **D-140 为什么用"纪元年份"做折盐而不是会话内的计数器**：纪年是既有的世界持久态（`Clock` 已随世界落盘），
  折进种子后"第几年看到哪张图"可复现、跨存档稳定；若是会话计数器，读档就归零回新手图，与"世界自己在走"冲突。
  era 0 即世界本原种子，新手期零行为变化。
- **地壳变动不单独配周期开关**：结点挂死 PERIOD_YEAR（每纪年一次），与 `settle_year` 的"居民生命周期"同拍，
  避免再引入一套可配周期参数的配置面；需要更稀的频率时再加 `balance` 段不迟。
