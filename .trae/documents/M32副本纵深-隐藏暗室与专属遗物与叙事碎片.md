# M32 副本纵深：隐藏暗室 · 专属遗物 · 层内叙事碎片（M-D 纵深 2）

> 承接 M29（BOSS/修正词条/主题）之上，按用户选定再给副本加三种纵深：**A 隐藏暗室与密道**、**C 副本专属遗物**、**D 层内叙事碎片**。本里程碑只做这三件，不做 B（BOSS 多阶段）。
> 铁则不变：规则层纯函数、不落盘、可无头钉测；数值全走 balance；新 class_name 需先 `--headless --import` 注册，再 `--test` 全量回归。

## 现状（M29 已落地）

- `Dungeon.layout` 产 24×18 楼层：外圈墙 + 单格岩屑作 blocked，宝箱/敌人落在可站空地。
- `DungeonModifiers`：0–2 条遗构词条每层叠深（倍率/偏置）。
- `DungeonBoss`：最下层 `《巨兽》`，击杀掉宝石+尸骸+保底稀有三件套。
- `theme_for` 每 5 层出主题层，决定怪物池类别与掉落偏向。
- 掉落 `_dungeon_roll_loot` 只从 weapon/armor/consumable 抽，材料/工具不进宝箱。

**缺口**：副本是"一层层刷怪捡宝箱"，几何只有墙+岩屑，没有任何"藏起来的东西"；没有副本专属的高档战利品，下本收益缺乏独有目标；层与层之间没有叙事勾连。

---

## 目标

给副本补上"纵深"的三股味道：

1. **A 隐藏暗室与密道**——楼层墙上随机藏一间被封死的暗室，走近按回车推开暗门；里面要么锁着一件专属遗物（C），要么是一条直通出口的密道捷径，要么埋着一段叙事碎片（D）。
2. **C 副本专属遗物**——新增 `relic` 类别装备模板，只从副本深处宝箱 / 隐藏暗室 / BOSS 口入袋，给"为什么要下本、为什么要往深走"一个独有收益。
3. **D 层内叙事碎片**——每层随机散落几段刻痕石（读一块记一段），集齐整座遗构的身世拼成一句结局，把层与层用故事串起来。

## 实现步骤

### 1. 隐藏暗室·规则层 `dungeon_hidden.gd`（新建，纯函数）

与 DungeonModifiers 同构：只读 balance + 楼层结构字典，不改 WorldState，可无头钉测。

- `place(layout: Dictionary, seed_key: String, depth: int, opts: Dictionary) -> Dictionary`
  - 输入：`Dungeon.layout` 产出的楼层（含 blocked/treasures/enemies）、种子键、层深、`balance.dungeon.hidden`。
  - 输出：**拷贝后的新楼层字典**，多挂 `hiddenRooms: []`。常量 `is_empty()`/无房时返回原样（`opened=false`）。
  - 判定：`depth >= minDepth` 且 `rng.next_int(10000) < chanceBp` 才开房；rng 用 `(seed_key.hash() ^ depth*… )` 确定性派生。
  - 雕室：在楼层一角的空闲矩形（约 3×2..5×3）砌一间，**内室各格 + 一道暗门格**全部塞进 `blocked`（封死、不可走），暗门落在内室临主厅的墙上；内室不与出口/出生点/既有宝箱/敌人重叠。房型 `kind` 从 `kinds` 里确定抽（treasure/passage/fragment）。
  - 每房回 `{key, kind, hatch:{x,y}, interior:[[x,y]...], treasure:{x,y}|null, opened:false}`。
- `reveal(layout: Dictionary, roomKey: String) -> Dictionary`
  - 解锁：把内室 + 暗门各格从 `blocked` 移除（于是可走）、`opened=true`；返回 `{opened:true, kind}`。已开/无此房返回 `{opened:false}`。**不落盘、可断言**（开前走不进、开后走进且能取到内室内容）。
- 三种 `<kind>` 内室内容：
  - `treasure`：内室放一枚宝箱格，内中**必掉一件遗物**（C）。
  - `passage`：内室远端放一个"密道口"；走入密道口直接把玩家移到**离出口最近的可站格**（跨层内捷径，跳过大半楼面）。
  - `fragment`：内室刻一段叙事碎片（D），读后记入会话。

### 2. 专属遗物·规则层 `dungeon_relics.gd`（新建，纯函数）

- `templates()`：从 `ContentLoader.get_items()` 过滤 `category=="relic"`。
- `roll_for(depth: int, rng: DeterministicRNG, modifiers: Dictionary) -> String`
  - 按 `balance.dungeon.relics.tierDepth` 分档取 `chanceBp`（浅层低、深处高），叠 `modifiers.lootRarityBias` 抬高；命中则在 relic 模板池抽一件 templateId，未命中回 `""`。
- `guaranteed(rng) -> String`：隐藏暗室 treasure 房用，必抽一件（可能偏高档）。
- 数据：`balance.dungeon.relics` 新子段；`items.json` 新增 3–4 件 `category:"relic"` 高稀有度装备（带 slot/attack/armor，effectText 写 Elona 味典故）。
- 接入（`main._dungeon_roll_loot`）：每只宝箱在普通 roll 之后多调一次 `DungeonRelics.roll_for`，命中则本箱改为遗物；隐藏暗室 treasure 房用 `guaranteed`。**不新造掉落表**，沿用"抽模板→`_creator.add_item`"链路。

### 3. 叙事碎片·规则层 `dungeon_story.gd`（新建，纯函数）

- `fragment_for(seed_key: String, depth: int, rules: Dictionary) -> {id, idx, total, text}`
  - 确定性：用 `(seed_key.hash() ^ depth*…)` 派生出"本层有没有、是第几段"；`balance.dungeon.story.fragments` 为碎片池，`total = fragments.size()`。
  - 相当层数的楼层才散一块（`chanceBp` 控制），碎片落在一块可站"刻痕石"上（近似副本内可互动物，与宝箱同格判定）。
- `assemble(session_seed: int, rules: Dictionary) -> Array`：列出全部碎片文案（供集齐时拼一句）。
- 数据：`balance.dungeon.story.fragments` 若干条（描述这座遗构的身世，符合 D 的荒诞口径）。
- 接入：`main` 加 `_dungeon_fragments: []`（会话态，不落盘）。踏上刻痕石即记一段；集齐 `total` 段在 `_status` 拼出那声感叹。与世界存档无关——读档关卡是会话奇迹（沿用"能派生就不落盘、会话态留场景"的口径，参照 M21 遭遇）。

### 4. `main.gd` 接线

- 状态：`_dungeon_hidden_rooms: Array = []`、`_dungeon_fragments: Array = []`。
- `_enter_dungeon` / `_dungeon_descend`：`Dungeon.layout` 后接 `DungeonHidden.place(_dungeon, seed, depth, rules.hidden)`，把 `hiddenRooms` 存 `_dungeon_hidden_rooms`；每层一并掷 `DungeonStory.fragment_for`。
- `_dungeon_interact`（回车）：若 `_dungeon_player` 邻近某未开暗门 → `DungeonHidden.reveal`；开的是 treasure 房补进一枚必掉遗物的宝箱（_dungeon_loot 对应项置遗物），fragment 房读一段，passage 房把玩家瞬移到出口旁。
- `_dungeon_walk_to` / `_dungeon_step`：踩上密道口(mark 由 layout 记录)→ 传送。
- `_dungeon_roll_loot`：普通箱并入 relic roll；隐藏房 treasure 用 guaranteed。
- `_leave_dungeon`：清空 `_dungeon_hidden_rooms`/`_dungeon_fragments`。

### 5. 视图/绘制

- `DungeonViewModel.build`：把 `hiddenRooms` 摊成 `hiddenHatches`（未开暗门）与 `hiddenInteriors`（已开内室壁垒`色块）清单，含 kind 标记供绘制。
- `DungeonPanel.draw`：暗门用偏紫的"暗门"色、内室用更深的暗房色 + 遗物/刻痕石描点；图例补一行。命中测试对暗门/密道口返 `HIT_HATCH`/`HIT_RELIC`/`HIT_FRAGMENT`。

### 6. 测试（`test_suite.gd` 追加，预计新增约 25–40 项）

- `DungeonHidden.place`：确定性（同种子同房）、`depth<minDepth` 无房、内室/暗门都在 blocked（开前不可走）、开距其他物件不重叠。
- `DungeonHidden.reveal`：开后内室/暗门可走、`opened=true`、重复开幂等；treasure 房 guaranteed 遗物模板存在于 items.json。
- `DungeonRelics.roll_for`：浅层低命中/深层高命中的方向；`lootRarityBias` 抬高命中；`templates()` 只含 relic。
- `DungeonStory.fragment_for`：确定性、`idx ≤ total`、文案非空；`assemble` 顺序齐全。
- main 无头：进一层带暗室、回车开房取遗物/读碎片、踩密道口直达出口、集齐碎片拼结局文案。

## 关键取舍（写进技术设计 9.32 节 D-144/D-145/D-146）

- **D-144 隐藏暗室为什么做成独立的 `DungeonHidden` 规则层而非塞进 `Dungeon.layout`**：`Dungeon` 承诺"只回答哪个格是墙/宝箱/敌人/出口"，暗室属于"藏起来的收益与捷径"，两种职责混在一起会让既有 24×18 几何测试与确定性契约松动；单独一层 `place`/`reveal` 纯函数既守住 Dungeon 的既有语义，又能被无头测试单独钉住"开前不可走近、开后可取物"。
- **D-145 遗物为什么只出副本而不产自商路/制作**：遗物要当"下本的独有收益"，若别处也能顺手搞到，副本就退化成随机遭遇；本里程碑先只让它出现在副本宝箱、隐藏暗室与 BOSS 口，保持"唯一来源"的稀缺性。数值走 `balance.dungeon.relics.chanceBp` 随深度抬升（浅层低、深处高），不给"蹲浅层刷遗物"留口子。
- **D-146 叙事碎片为什么接会话态而不是随世界落盘**：碎片是每层确定性派生、集齐才算完；但"我读了几块"是会话里的一次性进度，与 M21 遭遇/宝箱同属"会话奇迹"。读档回来那座遗构早已换层，碎片重派生即可——沿用"能派生就不落盘；一次性现象留会话"的铁则，不给世界存档加字段。
