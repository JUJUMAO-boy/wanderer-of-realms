# 里程碑 14：生产技能系统（野外采集 → 中间材料 → 成品 → 附魔，成品稀有度随熟练爬升）

## Context（为什么做）

本里程碑把这条「采集 → 中间 → 成品 → 附魔」的制造链跑通，先做一个覆盖五类机制的纵向切片，再在数据层写一份**材料大全**（用户要求，方便日后逐条补介绍）。

## 三个已确认的设计决策

1. **链路覆盖 = 全链路**（用户选）——采药/采矿/伐木 → 中间材料（铁锭/皮革/碳）→ 成品（武/防/药水/食物）→ 附魔。
2. **原料来源 = 野外采集**（用户选）——在城郊/野外执行采集动作（按技能与熟练度产出对应材料）+ **商店只售基础材料**（高级/中间材料不卖，只能采/造/掉）。
3. **成品稀有度随熟练爬升**（用户选）——锻造出的装备档位随制作技能熟练度阶梯抬升，接数值框架第 8 章。

## 设计核心规则

### 生产技能与熟练度
- 与战斗技能同源：**复用 `avatar.skills`（0..100）**。生产技能 id：`forge`(锻造) / `alchemy`(炼金) / `cooking`(烹饪) / `enchant`(附魔) / `herb`(采药) / `mine`(采矿) / `lumber`(伐木)。
- 熟练度成长对齐 M13「用进」口径：**每成功做成一件事（采一次 / 造一件 / 附一次魔）+1，钳 0..100**，直接落盘（本身就在 avatar.skills）。不引入新的成长系统。

### 材料（新增 material 类别）
- `content_loader.ITEM_CATEGORIES` 加 `"material"`。
- items.json 新增 material 模板：**基础**（铁矿石/木材/草药/兽皮/小麦/生肉/盐）与**中间**（铁锭/皮革）与**附魔/高级**（附魔粉尘）。基础材料进商店可购；中间/高级材料只能靠采集/制造/掉落，商店不卖。
- 新增消耗品类成品复用 consumable 类别（治疗药水已存在，再补耐力药水/烤面包/烤肉等）。

### 配方（新增 recipes.json）
- 配方结构：`{recipeId, skill, displayName, requiredLevel, ingredients:[{itemId,count}], outputs:[{itemId,count}], kind:(craft|enchant), resultRarity?}`。
- 配方集（纵向切片，覆盖全部五类机制，不贪大）：
  - 中间材料：铁锭 `铁矿石×2 → 铁锭` [forge 0]；皮革 `兽皮×1 → 皮革` [forge 0]；碳 `木材×1 → 碳` [forge 0]。
  - 锻造·武器：匕首 `铁锭×1` [forge 0]；长剑 `铁锭×2 + 木材×1` [forge 20]。
  - 锻造·防具：皮甲 `皮革×2` [forge 10]。
  - 炼金：治疗药水 `草药×2 → HP50 消耗品` [alchemy 0]；耐力药水 `草药×2 + 盐×1 → SP50` [alchemy 20]。
  - 烹饪：烤面包 `小麦×2 → SP20` [cooking 0]；烤肉 `生肉×1 + 盐×1 → SP40` [cooking 10]。
  - 附魔（kind=enchant，就地改实例）：附魔·锋利 `附魔粉尘×2 → 武器攻击 +10%` [enchant 40]；附魔·坚固 `附魔粉尘×2 → 护甲 +10` [enchant 40]。
- 附魔产物 **直接作用到玩家当前佩戴/指定的实例**，走 M8 `ItemInstance.locate`/词缀追加的口径（复用 `roll_modifiers` 的 target/value 写法，改成"固定 target/value"的词条写入），不做新子体系。

### 采集（新增 Gathering 核心）
- 城郊/野外选点执行采集。按地形/技能给一张产出表（`{itemId: weight}`），取一次产出 `1..N` 件并 `+1` 熟练。
- 三张默认表：`mining → 铁矿石(为主)`、`logging → 木材`、`herbalism → 草药(为主)，低权掉毒蘑菇`。产出表留在 recipes.json（`kind:"gather"`，材料来自"野外"这一隐含来源），方便日后补钓鱼/剥皮。
- 配合「商店只售基础」：不采就没高级货，逼玩家真去野外。

### 成品稀有度随熟练爬升
- 制造**装备类**产物时按 `craft_rarity(skill)` 定档：熟练 `0/40/55/70/85` 分别对应 `common/fine/rare/epic/legendary`。产物实例上记 `craftRarity`，并据此折价与显示档位标签（复用 `avatar_view_model.RARITY_LABELS`）。
- 消耗品/材料产物固定为模板档位，不爬梯。
- **本次不做**稀有度对战斗属性(baseDamage/armor)的重算——那套已由掉落侧"按稀有度选对应模板"覆盖；本里程碑先让造物师看到「档位与价格」反馈。

### 制作执行（新增 Crafting 核心，规则层 RefCounted）
- `craft(avatar_snapshot, recipeConclusion)` 流程：
  1. 熟练度门槛：`avatar.skills[recipe.skill] ≥ requiredLevel`，不足 → `PRECONDITION_FAILED「熟练度不足」`。
  2. 材料清点：逐条 `ingredients` 校验背包存量（`avatar.inventory` 计数）≥ count，不足 → `PRECONDITION_FAILED「材料不足：缺 ××」`。
  3. 有化身兜底。
  4. 扣料：从 inventory 减同名 templateId 计数（对齐 `economy._take_from_inventory` 口径）。
  5. 产出：`kind=craft` 用 `ItemInstance.new_instance` 生成产物并登记 `item_instances` + `inventory`；`kind=enchant` 就地改指定实例。
  6. 成长：`avatar.skills[recipe.skill] += 1`（钳 100）。
- 返回 `{ok, produced, expenses, gainedSkills}`，错误码沿用 `PRECONDITION_FAILED` 风格。

## 本次不做（留给后续）
- 稀有度对战斗属性(baseDamage/armor)的重算。（见上）
- 钓鱼 / 剥皮 / 采集以外的产出表扩充——先落采矿/伐木/采药三张。
- 生产技能对城市发展度/财富的月度联动（技能库 ch5 提到，另设里程碑）。
- 配方库数百条全落地（先给纵向切片）。
- 制作/采集的特效、动画、音效。
