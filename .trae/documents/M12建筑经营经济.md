# 里程碑 12：经营经济 + 城市建筑实体抽取（含等级与可投资升级）

## Context（为什么做）

里程碑 11（负重）已完成并通过 1613/1613 测试，本地已提交 `239e694`（推送因 GitHub 网络问题暂缓）。现在进入下一个工程模块。

用户选定方向 = **经营经济**，并附加硬性要求：**把「城市建筑」抽成一个独立的数据/实体概念（建筑类型 + 建筑等级）**，因为后续要**按「建筑 + 等级」做局内美术外观表现**，而不是把城市只画成一个点。

现状：`cities.json` 没有任何建筑字段；`City`（`game/src/core/city.gd`）只存六维、势力、NPC，`tier` 是派生值不落盘；《城市特色建筑与人口设定.md》1.1–1.8 已为八城各定义了 1 个地标 + 4 个功能建筑（共 40 个），1.9 节给了「Tier→建筑」对应表（废墟=残垣、村落=摊位水井、城镇=酒馆铁匠铺小神殿、城市=公会/功能建筑、大城=地标）。

因此本模块把建筑做成**一对实体**：
- **从城市派生**（可用等级 available_level）——由 city tier 做存在门槛 + 关联维度细化等级，**不落盘**（与 3.6 节、City.tier 同口径）。
- **玩家私有投资**（invested_level）——玩家花钱升级某城某建筑，**必须落盘**（像传奇航线是玩家私有状态，不可由城市状态反推）。

## 三个已确认的设计决策

1. 深度：**实体 + 可投资升级**（玩家花钱升级建筑；影响反哺城市维度或给玩家收益）。
2. 配置：**新建 `game/data/buildings.json` + `cities.json` 每城加 `buildings` 引用列表**。
3. 等级：**tier 门槛（存在/状态）+ 关联维度细化（同 tier 内分级）**。

## 设计核心规则

**可用等级（派生，不落盘）**：`available_level(cfg, city)`
- `city.get_tier() < cfg.minTier` → 0（建筑关闭/废墟，不贡献、不给玩家收益）
- 否则 `1 + clampi(floor((scaleDim - dtaTierLower) / balance.buildings.scaleStep), 0, maxRefine)`
  - `dtaTierLower` = 当前所处方位的 scaleDim 档下界（复用 `City.TIER_DEVELOPMENT_MAX`/`TIER_POPULATION_MAX` 那套阈值思想）。
  - `scaleStep`、`maxRefine` 放 `balance.buildings`。

```gdscript
# 伪码，实际落在 game/src/core/city_buildings.gd
func available_level(cfg, city) -> int:
    if city.get_tier() < _min_tier(cfg): return 0
    var floor_dim: int = _dim_floor_of(city.get_tier(), cfg.scaleDimension)
    var raw: int = (city.get_dimension(cfg.scaleDimension) - floor_dim) / maxi(1, _scale_step())
    return 1 + clampi(raw, 0, _max_refine())
```

**投资等级（落盘）**：`invested_level(world, cityId, buildingId)`，存 `WorldState.building_investments[cityId][buildingId]`。

**生效等级（= 城市自然 + 玩家投资，受全局上限钳制）**：
```gdscript
func effective_level(cfg, city, invested) -> int:
    return clampi(available_level(cfg, city) + invested, 0, _max_level())
```

**月度城市维度贡献（派生，像贸易路线一样折进 deltas）**：`monthly_contribution(cfg, effectiveLevel)`，把 `cfg.dimensionBonus.*` × effectiveLevel 折成某维的 milli，供 `settle_month` 折进该城当月 delta（路由收获同一套 `_apply_route_yields` 式处理）。

**玩家月收益（仅按投资部分）**：`player_income(cfg, investedLevel)` = 每投资 1 级给玩家每月铜币，叠加进世界模拟既有的 `_player_monthly_grouped_income`（`game/src/core/world_sim.gd` ~L800-823）——只有玩家自己投的那部分赚钱，城市自然等级不白给玩家钱（否则没投过钱的城也发钱）。
- **投资动作投的是 `avatar.money` 扣钱**：`invest_cost(cfg, currEffective)` = `balance.buildings.investCostBase + perLevel * (currEffective)`（花钱随档位递增）。投资**即时结清**（像买/锻造），不动城市六维 → 无需 `applyStateChange`，只改 `WorldState.building_investments` 与 `avatar.money`。

## 本次不做（留给后续）
- 真正的局内美术表现：只产出 `presentationHint`（如 `"forge_city_l3"`）供后续按 建筑+等级 渲染。用户本意是“先立实体/等级，后面再做美术”。
- 建筑功能口子（进锻造坊=铁匠铺等）不在本轮，避免超范围。
