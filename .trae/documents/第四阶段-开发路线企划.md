# 《轮回之书》第四阶段开发路线企划

> 上游：《游戏设计文档》第 4.3 节（锚点 NPC）、第 14 章（开发路线图「正式版」行）、第 11 章（隐藏人物图鉴）；《轮回之书-永恒者灵魂碎片主线剧本》（四幕结构、七片碎片、四种结局、第 13 章跨世继承、第 11 章总攻战役）；《轮回之书-乱入者交叉任务剧本》（CX-01~CX-12 全十二条）。
> 阶段划界：**第一阶段 = 底座与闭环（M1–M23）**；**第二阶段 = 世界框·大地图实体化（M24–M35）**；**第三阶段 = 世界怎么对待你（M36–M47）**；本企划 = **第四阶段**。
> 铁则不变：能派生就不落盘 / 代价无道德评价 / 生成优先于编排 / 死亡与损失不可逆；新 `class_name` 需 `--import`，全量回归 `--headless --path game -- --test` 须 0 失败。
> 当前基线：**4040 / 4040**，main 与 origin/main 同步（里程碑 47 收口）。

---

## 一、这一阶段要做什么（一句话）

第三阶段把"世界怎么对待你"做实了；第四阶段做**收束**——把设计文档里那条"横贯多世、可被选择是否深挖的暗线"《永恒者灵魂碎片》从**剧本**落成**可跨世推进的主线系统**，把已有与散落的零件（B4 的迷你判定、B2 的瓦洛克试炼、预置却从未写入的 `SoulRecord` 主线字段、既有城市事件/副本/BOSS）拧成一条**玩家能自己拼出真相**的线，收全十二条乱入者交叉任务、补全五位锚点 NPC、给出**完整多阶段终局战役**与**四种结局 / 后日谈**。

> 主线不锁进程（剧本 1 节原则）：它不阻塞任何玩法，玩家可以完全无视它——这一点在实现上必须守住，任何"不接主线就走不下去"的设计都不立项。

## 四、落地顺序建议（跨里程碑裁切）

> 原则：**先地基后枝叶、高杠杆先行**；每条里程碑都以「纯规则可无头钉测 + 全量回归 0 失败」为验收门槛，任何一步都可独立交付。

1. **D1**（主线碎片系统）—— 先立地基：没有"碎片 + 幕次 + 跨世推进"，D4/D5/D6 都无处挂。
2. **D3**（城市事件交叉 CX-01~06）—— B4 的 `CrossTrial` 已备好、城市事件入口也已存在，**这六条不依赖 D1**，先落、先把"一句奏、一场球"接到玩家真能走到的地方。
3. **D2**（锚点 NPC 完整线）—— 给碎片系统安上"揭示者"，让真相有嘴。
4. **D4**（主线交叉 CX-07~12）—— 待 D1/D2 就位，乱入者才能在主线节点上登场。
5. **D5**（终局战役）—— 三幕揭示后发起总攻，多阶段战役收束暗线。
6. **D6**（四种结局与后日谈）—— 收口整条主线。

> 特别标注：**D1 与 D5 是本阶段的唯二大件**（同 A3/C1/M29 量级），都建议各自再拆成「纯规则 → 接线 → 界面」三小步，别一把梭；D1 的纯规则先把"碎片/幕次/跨世继承"钉死，D5 的多阶段结构先钉"阶段推进与阶段切换判定"再堆波次内容。

## 五、已拍板的边界（定了不再反悔）

1. **主线落盘**：与"能派生就不落盘"不同，主线是**玩家进度**——写进 `SoulRecord.main_quest_progress` / `anchor_relations`（这两个字段本就为此预留、随灵魂存档）。
2. **幕次推进**：按「**已集碎片数 + 关键揭示动作**」**双条件**推进（不靠单纯计数、也不靠一次性过场），保住"拼图感"——集齐碎片还得听锚点 NPC 把话说透才进下一幕。
3. **终局战役**：做剧本 11 节的**完整多阶段总攻战役**（多波敌人 + 特殊机制 + 灰袍者 BOSS 完整技能表），复用 M29 副本/BOSS 规则层承载。
4. **乱入者交叉任务**：本轮 **CX-01~CX-12 十二条全做**（城市事件交叉六条 + 主线交叉六条）。
5. **锚点 NPC**：五位**全给相遇点与完整揭示分支**（鸦 / 欧尔塔 / 瓦洛克 / 伊莉丝 / 收债人）。

## 六、这一阶段的验收口径（贯穿）

- 每条里程碑收尾：`--import` 注册新 `class_name`（若有）→ 新增测试 → 全量回归 **0 失败** → 更新 README 里程碑表 + 技术设计文档 9.x 节（D-编号续里程碑 47 的 D-193 之后）→ 本地提交 → 授权后推送 origin/main。
- 六条里程碑独立验收，互不阻塞；D1 的纯规则层先钉死"碎片/幕次/跨世继承"三件事，后面 D2~D6 都对着它说话。
- 守住剧本 1 节原则：**主线不锁进程**——任何一条里程碑都不得让"不接主线"的玩家走不下去。
