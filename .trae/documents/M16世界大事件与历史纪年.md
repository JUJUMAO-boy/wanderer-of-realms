# 里程碑 16：世界大事件与历史纪年

## Context（为什么做）

《轮回之书》的核心招牌是"世代更迭里世界有记忆"。现状拆开看：单城事件（`EVENT_INSTANCE`，了结后仅用于 recurrence 判定）、城市六维历史（趋势线、只留窗口月数、破例动态保留）、每世一份的 `life-NNN.json` 世代档案——三块各自为政，**缺一根跨城、跨代的纪年轴**把"这个世界因我改了什么"沉淀成后人能翻开看的历史。城市面板能回答"某城为何变了"，但没有一个视图能回答"这一百年里发生过哪些大事、我的一生留下了什么"。

这正是设计文档 §8.7 观察点一（"因我做了什么，这座城市改变了"）与 §8.8 演化不可观测风险的落点：M6.3 城市状态面板 + 委托反馈接完后，还缺一层**叙事性的跨代记忆**。M16 把这根纪年轴做出来：新的大事件成为世界级记忆、随世界落盘、做成第 11 个视图供玩家随时翻阅。

探索确认现状：
- 事件入口/触发在 [event_system.gd](file:///c:/Users/YUJINYU/Desktop/侠客游/game/src/core/event_system.gd)：`active()` 按城市过滤、`check_triggers()` + `apply_monthly_drain()` 在 [world_sim.gd](file:///c:/Users/YUJINYU/Desktop/侠客游/game/src/core/world_sim.gd) 月度结算里调用，把触发/持续事件写入 `notable`；`world_state.events: Array` 保留已了结实例用于 recurrence。
- 城市六维历史在 `world_state.gd`：动态保留窗口月数，趋势线用。
- 世代档案在 [save_io.gd](file:///c:/Users/YUJINYU/Desktop/侠客游/game/src/autoload/save_io.gd)：`life-NNN.json` 每世追加，只增不改。
- 主场景有 11 个视图常量（`VIEW_MAP..VIEW_CRAFTING = 0..10`），新视图须接入 `main.gd` 五处 `match _view` 分发（`_refresh/_unhandled_input/_handle_mouse_button/_hit_test_at/_draw`）+ `VIEW_HINTS` + 城市面板入口键。地图键位已占用：T 城/C 角色/X 走私/Q 委托/E 事件/R 商铺/V 制作台/B 遭遇/F 采集/WASD·方向键移动。**`H`（History）空闲**。

## 设计决策

1. **纪年轴 = 世界级实体 `world.chronicle`**，随世界存档（`world_state.gd`），不是派生的趋势线而是**真实条目落盘**——纪年的价值正在于"换了代还能翻开"，必须跨存档保留。每条纪年：`{id, year, month, kind, title, cityId(可选), detail, attribution}`，`attribution` 标注来源（城市事件 / 六维升阶 / 玩家世系 / 走私等等）。
2. **大事件来源（写入纪年的触发点）**：
   - 城市事件：当一件事件的**等级足够高**（模板加 `chronicleBp` 权重，按 `city.events` 的月贡献 / 事件 severity 折算）时，在 `world_sim` 月度结算已把它写入 `notable` 的同时，额外产出**一条跨城世界纪年**（title 带城市名，写明"XX城发生了XX"）。普通琐碎事件不进纪年，避免被刷屏稀释。
   - 六维演化里程碑：某城某维**升阶/降级**（`city_buildings` 已能派生等级）时写一条纪年——这是"世界在变"的直接可见化。
   - 玩家世系：每次**转生**（坐化 / 新诞生）由 `save_io` 追加世代档案的同一处写一条纪年（title 如"第 N 世的传奇落幕"），把个体的生命锚进世界时间线。跨代可观测性的主入口。
   - （可选，先不做）走私航线开通等世界级手动行为，留后续加。
3. **过滤阈值**：`chronicle` 用 `ContentLoader.get_balance_section("chronicle")` 配 `minChronicleWeight` 过滤城市事件等级，未达阈值只留单城记录、不进纪年。规则层纯函数，就地写 `world`。
4. **新视图 `VIEW_HISTORY`（=11）**：仿 `EventPanel`（单城事件面板，纵向行 + 右列明细 + 页脚）。列表 = 全世界纪年**按时间倒序**，`↑↓` 选一行，右列展开该条 detail 与归属来源，`←→` 分页（纪年条目多时）。入口：**地图 `H` 键**（History），与既有 `E` 打开"城中大事"并列——E 看当下某城，H 看跨代全史。
5. **规则层/视图层分层**：新建 `Chronicle`（RefCounted 规则层，`record(world, entry)` / `chronicle_weight(template)` / `entry_for_event/resolve`）与 `ChronicleViewModel`（纯函数：`build(world, sort="desc", cursor)` 产 `{rows, selected, cursor, count}`）+ `ChroniclePanel`（仿 `EventPanel` 画）。沿用"规则层就地改 world、视图层纯函数该显示什么、面板怎么画"的既有架构。
