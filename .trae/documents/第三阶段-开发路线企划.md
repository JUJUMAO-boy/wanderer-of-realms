## 一、这一阶段要做什么（一句话）

第二阶段把"世界"接活了；第三阶段把"**世界怎么对待你**"做实——身份、关系与时间的厚度，而不是再来一套新战斗。三条主线并列推进，先评分、后裁切。

- **主线 A · 身份·社交·长期目标**：你在世界里是"有名字的人"——口碑、声望地位、家族、职业任务链。
- **主线 B · 终局·叙事纵深**：把"玩到头的目标"与"菜单里的人在说话"补全——试炼、乱入者、交叉任务、文风验收。
- **主线 C · 世界动态·生态闭环**：让世界在**大时间尺度**上互咬——野心、流言、地壳变动下的生意连锁。

## 四、落地顺序建议（跨主线裁切）

> 原则：**先小后大、先内容后系统、高杠杆先行**；所有里程碑都以「纯规则可无头钉测 + 全量回归 0 失败」为验收门槛，任何一步都可独立交付。

1. **A1**（口碑·四条内核验收化）—— 便宜、影响全菜单，先立文风口。
2. **B1**（委托对话模板）—— 内容小件，把 M4 补成"会说话"。
3. **C4**（势力兴衰纪年化）—— 接史书，为 C1 铺地基。
4. **A2**（城市声望·地位）—— 把声誉从数值变身份，主线 A 的第一个"系统件"。
5. **C2**（传闻真假传播）—— A1 落地成会动的流言。
6. **B2 / B3 / B4**（叙事纵深三件）—— 按内容消化节奏内插。
7. **A4**（职业任务链）、**C3**（生意连锁）—— 中件内容/系统，政治站位需求。
8. **A3 / C1**（婚姻家族 / 野心势力）—— 两个大件压轴，各自独立里程碑、分步钉测，回归影响最高。

> 特别标注：**A3 与 C1 是唯二的大件**，都建议各自再拆成"纯规则 → 接线 → 界面"三小步，别一把梭。

## 五、需要你拍板的边界（定了不再反悔）

1. **A3 婚姻是否触碰"死亡不可逆"内核**：默认严守不变——配偶是可失去的，丧偶进入下一世不挽留（与转生口径一致）。若要软化需你明说。
2. **A1 的文风验收筛做到哪一层**：默认覆盖**所有现役菜单/结局文案**过 P8 筛（每 300 字至少一处荒诞细节）；若只做新增文案则标注。
3. **C1 城市野心是否落盘**：沿用铁则默认**派生态不落盘**（同 M2/M30 口径）；落盘则需存档迁移，除非你点名。
4. **B4 迷你游戏与交叉战斗是否要真可玩**：默认给**规则层 + 可无头钉测**的最小可玩形态，先不做表演级美术，界面沿用既有面板样式。

## 六、这一阶段的验收口径（贯穿）

- 每条里程碑收尾：`--import` 注册新 class_name（若有）→ 新增测试 → 全量回归 **0 失败** → 更新 README 里程碑表 + 技术设计文档 9.x 节 → 本地提交 → 授权后一次性代理推送。
- 三条主线各自独立验收，互不阻塞；每条先做的高杠杆件先把"口碑/文风"与"会说话的对白"这两根文风锚立起来，后面所有内容件都对这两根锚说话。
